# Editions privacy policy

Public policy for Editions, operated by Summers Media. Privacy and support: david@summers.media.

This repository contains only the static policy page and its stylesheet. It contains no Editions application source, photograph fixtures, library databases or credentials.

GitHub Pages publishes `main` from the repository root. `index.html` is the policy; `#support-and-beta-feedback` is its support contact section. `.nojekyll` keeps publication buildless. There are no scripts, forms, external fonts or analytics.
